# 🌐 Network Security Toolkit

A beginner-friendly educational toolkit for learning basic networking and cybersecurity concepts.

## 🚀 Features

- 🌐 IPv4 Validator
- 🔌 Port Validator
- 🖧 Subnet Mask Validator
- 🧮 CIDR Calculator
- 📚 Common Ports & Protocols
- 🌐 IPv4 Class Checker

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Git & GitHub
- GitHub Pages

## 🎯 Purpose

This project was created as a learning project to practice:

- IPv4 addressing
- Subnetting
- CIDR notation
- Network ports and protocols
- JavaScript validation
- Git and GitHub workflow

## 🌍 Live Demo

The project is deployed using GitHub Pages.

## 📌 Disclaimer

This toolkit is designed for educational purposes.
It performs basic calculations and validation locally in the browser.
